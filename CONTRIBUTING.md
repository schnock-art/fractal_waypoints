# Contributing

Contributions and ideas are welcome, including bug reports, feature discussions, documentation improvements, experiments, reproducible test cases, and mapping or preset ideas. Use the [Fractal Waypoints GitHub repository](https://github.com/schnock-art/fractal_waypoints) to open an issue or pull request and describe the change or observation clearly.

## Development

Use the commands already listed in the README:

- `npm install` installs the project dependencies.
- `npm run dev` starts the local app.
- `npm run check` type-checks the project.
- `npm test` runs the unit tests.
- `npm run test:e2e` runs the browser tests.
- `npm run build` type-checks and builds the production app.

Please include a focused explanation and relevant test or reproduction steps with code changes. Documentation and small error corrections can be reviewed through the normal pull request process.

## Contributor rights

Fractal Waypoints is dual-licensed. To preserve the project's ability to offer both AGPL and commercial licensing, contributions may require a Contributor Licence Agreement or another explicit contributor-rights arrangement before they can be merged. No such arrangement is established by this guide, and opening a pull request does not assign copyright.

Until a contributor-rights process is formally established, issues, discussions, bug reports and design feedback are welcome, and small documentation or error corrections can be reviewed normally. Please discuss substantial external code contributions with the maintainer before beginning significant implementation work.
